# CPS 242 Django Project

## Worker Payroll and Advances Management System

Created by: Zwe Htet  
University of Dayton  
Department of Computer Science

A Django-based project focused on managing employee time tracking, wage calculations, cash advances, and payslip generation.

## Overview
This application is designed to support payroll-related workflows for workers, including:

- Timesheet entry and tracking
- Automatic wage computation
- Cash advance requests and records
- Payslip generation and review

## Features
- Employee work-hour management
- Payroll calculation logic
- Advance monitoring for workers
- Simple reporting and record keeping

## Tech Stack
- Python
- Django
- SQLite / database-backed storage

## Project Goal
The goal of this project is to provide a practical payroll management solution for academic coursework and software development practice.
